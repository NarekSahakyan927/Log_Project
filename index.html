Մաս 1 · Մաթեմատիկական հիմքեր

Ի՞նչ է լոգարիթմը

Լոգարիթմը պատասխանում է հարցին՝ հիմքը ինչ աստիճանի բարձրացնենք, որ ստանանք տվյալ թիվը։

loga x = y  ⇔  ay = x

Այստեղ a-ն հիմքն է, x-ը՝ արգումենտը, y-ը՝ արդյունքը։ Պայմաններ՝ a > 0, a ≠ 1, x > 0։

Օրինակ՝ log2 8 = 3, որովհետև 23 = 8։ Նաև log10 1000 = 3, որովհետև 103 = 1000։

Հիմնական հատկությունները

loga(xy) = logax + logay
loga(x/y) = logax − logay
loga(xr) = r · logax
logax = logbx / logba

Վերջինը հիմքի փոփոխման բանաձևն է։ Հաշվիչները և ծրագրավորման լեզուները հենց դրանով են հաշվում կամայական հիմքով լոգարիթմ։ Ստուգում՝ log2 8 + log2 16 = 3 + 4 = 7 = log2 128։

Ապացույց՝ արտադրյալի հատկության

Դիցուք logax = m և logay = n։ Սահմանումից x = am, y = an։ Այդ դեպքում xy = am·an = am+n, հետևաբար loga(xy) = m + n = logax + logay։ ∎

Երեք կարևոր հիմք

Հիմք 2 · log2

Երկուական լոգարիթմ։ Ալգորիթմների և բիթերի լեզուն։

Հիմք 10 · log10

Տասական լոգարիթմ։ Տասնորդական կարգեր, սանդղակներ։

Հիմք e · ln

Բնական լոգարիթմ, e ≈ 2,71828։ Աճի և փոփոխության մոդելներ։

Լոգարիթմական ֆունկցիայի հատկությունները

  • Սահմանման տիրույթ՝ x > 0, արժեքների բազմություն՝ բոլոր իրական թվերը։
  • Գրաֆիկն անցնում է (1, 0) կետով, որովհետև loga1 = 0։
  • Եթե a > 1՝ ֆունկցիան աճող է, եթե 0 < a < 1՝ նվազող։
  • y = ax և y = logax ֆունկցիաները փոխադարձ հակադարձ են, գրաֆիկները համաչափ են y = x ուղղի նկատմամբ։

Գրաֆիկը փոխելու համար գնա Փորձասենյակ։

Պատմություն. 1614 թվականին շոտլանդացի Ջոն Նեպերը հրապարակեց լոգարիթմները։ Աղյուսակները բազմապատկումը դարձնում էին գումարում, և դարեր շարունակ աստղագետներն ու նավաստիները դրանցով էին հաշվում։ Նույն գաղափարը այսօր աշխատում է ալգորիթմներում։

Մաս 2 · Համակարգչային գիտություն

Ինչո՞ւ են լոգարիթմները կարևոր ծրագրավորման մեջ

Ծրագրի արագությունը կախված է ոչ միայն համակարգչից, այլև քայլերի քանակից։ Այդ քանակը նկարագրվում է ժամանակային բարդությամբ. գործողությունների թիվը որպես մուտքային տվյալների n չափի ֆունկցիա։ Big O գրառումը տալիս է աճի կարգը, անտեսելով հաստատուն գործակիցներն ու փոքր անդամները։

Ինչպե՞ս է առաջանում O(log n)-ը

Եթե ամեն քայլից հետո մնացած տիրույթը կիսվում է, k քայլից հետո մնում է մոտ n / 2k տարր։ Երբ մնում է 1 տարր՝

n / 2k ≤ 1  ⇒  2k ≥ n  ⇒  k ≥ log2 n

Այսինքն՝ քայլերի թիվը համեմատական է log2n-ին։ Եթե խնդրի չափը կրկնապատկվի, քայլերը կավելանան ընդամենը մեկով։

Կարևոր պայման։ Binary Search-ը աշխատում է միայն տեսակավորված տվյալների վրա։ Եթե տվյալները նախ պետք է տեսակավորել, այդ ծախսը նույնպես հաշվի է առնվում։ Նաև O(log n)-ը աճի կարգ է, ոչ թե վայրկյաններ, և ցանկացած ծրագիր, որտեղ կա log ֆունկցիա, պարտադիր լոգարիթմական չէ։

Հիմա այս ամենը տեսնենք գործնականում։

O(log n), O(n), O(n²)

Տեղաշարժիր սլայդերը և համեմատիր վատագույն դեպքում պահանջվող քայլերը։

Մաս 5 · Ալգորիթմը մոտիկից

Ցուցակը տեսակավորված է (1-ից 32)։ Ամեն քայլում ստուգվում է միջին տարրը, և պահվում է միայն այն կեսը, որտեղ կարող է լինել թիվը։ Կանաչը որոնման տիրույթն է, դեղինը՝ միջինը։

Սեղմիր «Սկսել նոր որոնում»։

mid = ⌊(left + right) / 2⌋ · 32 տարրի դեպքում առավելագույնը ⌊log232⌋ + 1 = 6 ստուգում։

Մաս 6 · Մաթեմատիկական փորձասենյակ

Փոխիր հիմքը, հաշվիր, ուսումնասիրիր

Լոգարիթմի հաշվիչ

Հաշվարկը կատարվում է հիմքի փոփոխման բանաձևով՝ ln(x) / ln(a)։

Փոփոխվող հիմքով գրաֆիկ

Թվի վերլուծություն

Թվանշաններ = ⌊log10n⌋ + 1։ Բիթեր = ⌊log2n⌋ + 1՝ այդքան բիթ է պետք թիվը հիշողության մեջ պահելու համար։

Էնտրոպիա. n հավասար հավանական տարբերակ ունեցող ընտրության տեղեկությունը log2n բիթ է։ Մետաղադրամի համար դա 1 բիթ է, զառի համար՝ մոտ 2,58 բիթ, 8 տարբերակի համար՝ 3 բիթ։ Ընդհանուր դեպքում H = −Σ p·log2p, և դա տվյալների սեղմման տեսական սահմանն է։

Մաս 7 · Գործնական ծրագրավորում

Python-ի օրինակներ

Պատճենիր կոդը և գործարկիր քո համակարգչում (Python 3), կամ առցանց՝ python.org/shell։ «Արդյունք» բլոկները ցույց են տալիս, թե ինչ պետք է տպվի։

1. Լոգարիթմ հաշվելը

import math

print(math.log2(64))      # 6.0
print(math.log10(1000))   # 3.0
print(math.log(math.e))   # 1.0  (բնական լոգարիթմ)
print(math.log(8, 2))     # 3.0  (կամայական հիմք)

Python-ում math.log(x)-ը բնական լոգարիթմն է, log2-ը՝ հիմք 2, log10-ը՝ հիմք 10։ Արգումենտը պետք է լինի դրական։

2. Binary Search

def binary_search(items, target):
    left, right = 0, len(items) - 1
    steps = 0

    while left <= right:
        steps += 1
        mid = (left + right) // 2

        if items[mid] == target:
            return mid, steps
        if items[mid] < target:
            left = mid + 1
        else:
            right = mid - 1

    return -1, steps


items = list(range(1, 1_000_001))   # տեսակավորված ցուցակ
print(binary_search(items, 777_777))

  
Ամեն կրկնության ժամանակ տիրույթը կիսվում է։ Ժամանակային բարդությունը O(log n) է, լրացուցիչ հիշողությունը՝ O(1)։ Վերևի արդյունքը հաշվարկվել է այս էջում նույն ալգորիթմով։

import math

for n in (10, 1_000, 1_000_000, 1_000_000_000):
    worst = math.floor(math.log2(n)) + 1
    print(f"n = {n:>13,}   binary ≤ {worst:>2}   linear ≤ {n:,}")

Հավասարակշռված որոնման ծառի բարձրությունը մոտ log2n է, ուստի որոնումն ու թարմացումը հաճախ O(log n) են։

    
Տեսակավորում
Արդյունավետ տեսակավորման ալգորիթմները (merge sort, heap sort) աշխատում են O(n log n) ժամանակում։ Սա համեմատություններով տեսակավորման տեսական սահմանն է։

    
Տեղեկատվության չափում
log2-ը չափում է տեղեկատվությունը բիթերով։ 8 հավասար հավանական տարբերակից մեկի ընտրությունը 3 բիթ է։

    
Կոմպրեսիա
Լոգարիթմը ինքնին ֆայլ չի սեղմում, այլ օգնում է գնահատել տվյալների պարունակած տեղեկատվության չափը (էնտրոպիա)։

    
Գիտական սանդղակներ
Լոգարիթմական սանդղակները (դեցիբել, pH, Ռիխտեր) հարմար են շատ լայն միջակայքի մեծություններ ներկայացնելու համար։

  







  

  
Մաս 9 · Գիտելիքների ստուգում

  
Փոքրիկ թեստ

  
8 հարց։ Ընտրիր պատասխանները և սեղմիր «Ստուգել»։

  

  

  







  

  
Եզրակացություն

  
Մաթեմատիկայում լոգարիթմը հակադարձում է ցուցչային գործողությունը։ Ալգորիթմներում այն նկարագրում է այն դեպքերը, երբ ամեն քայլում խնդրի չափը փոքրանում է հաստատուն գործակցով։

  
Binary Search-ը այս կապի ամենապարզ օրինակն է. տեսակավորված տվյալների վրա այն կիսում է տիրույթը, և քայլերի թիվը աճում է log2n-ի կարգով։ Նույն աճ հանդիպում է հավասարակշռված ծառերում և ինդեքսներում։

  
Գլխավոր բացահայտումը. երբ խնդրի չափը բազմապատկվում է, լոգարիթմական ալգորիթմի քայլերի թիվը աճում է շատ ավելի դանդաղ, քան գծային կամ քառակուսային ալգորիթմինը։ Ծրագրավորողին լոգարիթմները պետք են ալգորիթմները վերլուծելու, տվյալների կառուցվածքներ ընտրելու և մեծ խնդիրների համար արդյունավետ լուծումներ նախագծելու համար։
