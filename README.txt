LOG.LAB — Լոգարիթմները ծրագրավորման մեջ

Գործարկում
1. Ներբեռնիր և բացիր ZIP արխիվը։
2. Բացիր logarithms_project պանակը։
3. Կրկնակի սեղմիր index.html ֆայլի վրա կամ բացիր այն Chrome / Firefox / Safari դիտարկիչով։
4. Ինտերնետ պետք չէ. կայքը աշխատում է տեղային և արտաքին JavaScript գրադարան չի օգտագործում։

Կայքի հնարավորությունները
- Հայերեն տեսական նյութ և մաթեմատիկական բանաձևեր
- Լոգարիթմական ֆունկցիայի գրաֆիկ
- O(log n), O(n), O(n²) աճերի ինտերակտիվ համեմատություն
- Binary Search քայլ առ քայլ ցուցադրում
- Փոփոխվող հիմքով գրաֆիկ և լոգարիթմի հաշվիչ
- Python օրինակներ և ինտերակտիվ Python Lab (Pyodide)
- 5 հարցից բաղկացած ինքնաստուգման թեստ
- Աղբյուրների ցանկ

Նշում
Գրաֆիկներն ու գործողությունների քանակները ուսուցողական պատկերումներ են։ Դրանք չեն չափում իրական համակարգչի աշխատանքի վայրկյանները։

Python Lab-ի նշում
- Կայքի ներսում Python կոդ գործարկելու համար առաջին անգամ անհրաժեշտ է ինտերնետ կապ՝ Pyodide միջավայրը բեռնելու նպատակով։
- Հետագա գործարկումները նույն դիտարկիչում կարող են օգտագործել քեշավորված ֆայլերը։
- Python-ը աշխատում է օգտատիրոջ դիտարկիչում, ոչ թե հեռավոր սերվերում։
